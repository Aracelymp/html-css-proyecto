## 📌 Descripción del Proyecto

**Ari Papelería** es una plataforma e-commerce dedicada a la venta de productos de papelería creativa y artículos personalizados (cuadernos a medida, papelería fina, destacados y accesorios de escritorio). 

El proyecto abarca la creación del frontend responsivo, accesible y semántico, incluyendo navegación fluida, diseño mediante hojas de estilo personalizadas y la validación de formularios de inicio de sesión y registro mediante JavaScript.

---

## 🛠️ Tecnologías Utilizadas

* **HTML5:** Estructuración semántica del sitio web (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`).
* **CSS3:** Estilos visuales externos (`style.css` y `register.css`).
* **JavaScript (Vanilla JS):** Lógica del cliente y validación interactiva de datos de usuario.
* **Git & GitHub:** Control de versiones colaborativo utilizando la metodología de ramas (`feature/agregando-login`).
